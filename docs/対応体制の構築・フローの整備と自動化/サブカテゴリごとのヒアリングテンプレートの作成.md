    # 🧾 情報システム部共通ヒアリング起票テンプレート設計書（第1版）
    
    ---
    
    ## 🧭 設計方針
    
    | 項目                   | 内容                                                                                    |
    | ---------------------- | --------------------------------------------------------------------------------------- |
    | **目的**               | Slackでの一次ヒアリング内容をもとにNotionへ自動起票し、属人化のないタスク化を実現する。 |
    | **対象範囲**           | 情報システム部全体（EX・基盤・開発・セキュリティ各ドメイン）                            |
    | **設計思想**           | 「Slackで最小入力 → Notionで詳細整理」Slackフォームは5〜7問以内に統一。                 |
    | **利用情報の自動取得** | 利用者名・所属部署はSlackプロフィール情報から自動取得。                                 |
    | **Notion連携**         | Zapier or Slack Workflow Builderを介してNotion DBに自動登録。                           |
    | **優先度算出**         | 「影響範囲 × 緊急度 × 希望時期」の組合せでスコアリング算出（詳細は後述）。              |

    ## 🧩 共通質問項目（Slackフォーム）
    
    | 区分         | 質問内容                                       | 形式                                   | 自動 or 入力 | Notionフィールド対応 |
    | ------------ | ---------------------------------------------- | -------------------------------------- | ------------ | -------------------- |
    | 利用者情報   | 利用者名                                       | 自動取得                               | 自動         | 依頼者               |
    | 所属部署     | 所属部署名                                     | 自動取得                               | 自動         | 所属部署             |
    | 対応種別     | どの種類の依頼ですか？                         | 選択（6分類）                          | 手動         | テンプレート種別     |
    | 対象範囲     | 対象機器／システム／サービスを選択してください | プルダウン                             | 手動         | 対象範囲             |
    | 状況・目的   | 今回の内容に最も近いものを選択                 | 選択（障害／設定変更／調査／追加など） | 手動         | 依頼種別             |
    | 影響範囲     | この事象はどの程度影響していますか？           | 選択（全体／一部／個人）               | 手動         | 影響範囲             |
    | 希望対応時期 | いつまでに対応が必要ですか？                   | 選択（ASAP／今週中／日付指定）         | 手動         | 希望時期             |
    | 詳細内容     | 詳細な内容をご記入ください                     | 自由記述                               | 手動         | 詳細内容             |
    | 添付資料     | 参考画像やファイル                             | 添付                                   | 任意         | 添付資料             |

    ## ⚙️ 優先度算出ロジック（スコア式）
    
    | 要素                           | 値                                   | 重み |
    | ------------------------------ | ------------------------------------ | ---- |
    | 影響範囲：全社／部門／個人     | 3／2／1                              | ×2   |
    | 希望時期：ASAP／今週中／指定日 | 3／2／1                              | ×1.5 |
    | 依頼種別：障害／設定変更／要望 | 3／2／1                              | ×1   |
    | **合計スコア**                 | （影響×2）＋（時期×1.5）＋（種別×1） | -    |
    
    | スコア範囲 | 優先度ラベル |
    | ---------- | ------------ |
    | 8点以上    | 🔴 緊急       |
    | 5〜7点     | 🟡 通常       |
    | 4点以下    | 🟢 低         |

    ## 🔄 Slack → Notion 連携フロー概要
    
    ```
    Slackフォーム送信
    　↓
    Slack Workflow Builder / Zapierでトリガー
    　↓
    入力内容をJSON変換 → Notion APIにPOST
    　↓
    Notion DBに新規レコード作成（ステータス：未着手）
    　↓
    優先度ロジック自動計算
    　↓
    担当ドメイン・担当者に通知（Slackチャンネル連携）
    
    ```
